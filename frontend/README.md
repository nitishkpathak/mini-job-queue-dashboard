# Mini Job Queue - React Frontend

React.js dashboard frontend built with Vite and Tailwind CSS.

## Features

- Real-time job state management
- Filter by status (`pending`, `running`, `completed`, `failed`)
- Status counter cards
- Modal form for creating jobs
- Context-aware state transition buttons
- Custom notifications for API errors and race conditions

## Run Locally

```bash
npm install
npm run dev
```

App runs on `http://localhost:3000`.
